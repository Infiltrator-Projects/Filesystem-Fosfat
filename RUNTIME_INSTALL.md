# Fosfat native installation

The runtime release builds the read-only Common V2 provider at the pinned source revision and installs `/System/Filesystems/FOSFAT.so` and `/System/Resources/Documentation/Filesystem-Fosfat.pdf`. Unsupported operations are not advertised. Native compilation uses CPU-specific optimisation; no PGO or physical firmware qualification is claimed. The earlier documentation-only package, if published, is superseded by this higher-version runtime package of the same identity.
